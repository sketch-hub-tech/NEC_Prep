## 1.1 Basic Concepts

### Fundamental quantities
- **Voltage (V/E):** potential difference; unit **volt (V)**.
- **Current (I):** rate of flow of charge; **I = Q/t**; unit **ampere (A)**; conventional direction = positive charge flow.
- **Resistance (R):** opposition to current; unit **ohm (Ω)**.
- **Power (P):** rate of energy conversion; **P = V·I = I²R = V²/R**; unit **watt (W)**.
- **Energy (E):** **E = P·t** = V·I·t; unit **joule (J)** or **kWh** (1 kWh = 3.6 MJ).

### Ohm's Law
```
V = I · R
```
Applies to ohmic/linear resistors only (constant R).

### Conductor / insulator / semiconductor
- **Conductor:** low resistance, many free electrons (metals: Cu, Al).
- **Insulator:** very high resistance, no free electrons (rubber, glass, plastic, mica).
- **Semiconductor:** resistivity between; Si, Ge; 4 valence electrons.

### Resistor networks
| Connection | Equivalent | Key property |
|---|---|---|
| Series | `R = R1+R2+...` | Same current, voltage divides |
| Parallel | `1/R = 1/R1+1/R2+...` | Same voltage, current divides |
| Two parallel equal | R/2 | — |
| n equal in series | n·R | — |

### Kirchhoff's Laws
1. **KCL (current law):** At any node, algebraic sum of currents = 0 (Σ Iin = Σ Iout). — Conservation of charge.
2. **KVL (voltage law):** In any closed loop, algebraic sum of voltages = 0 (Σ IR drops = Σ emf). — Conservation of energy.

### Star (Y) ↔ Delta (Δ) conversion
- Y→Δ : `R12 = (R1R2 + R2R3 + R3R1)/R3`, etc.
- Δ→Y : `R1 = R12·R31 / (R12+R23+R31)`, etc.
- **Equal resistances:** `R_y = R_Δ/3` (star = 1/3 of delta).

### Circuit classifications
- **Linear:** V–I relation on straight line (obey Ohm's law); nonlinear (diode, Zener).
- **Bilateral:** same behavior both current directions (R); **unilateral:** direction-dependent (diode).
- **Active elements:** supply energy (voltage/current sources, transistors). **Passive elements:** consume/store (R, L, C).

## 1.2 Network Theorems

All theorems apply to **linear** circuits.

1. **Superposition theorem:** In a linear network with multiple sources, the response (current/voltage) in any branch = algebraic sum of responses from **each source acting alone** (other sources: voltage → short, current → open). Power is **NOT** superposable.

2. **Thevenin's theorem:** Any linear two-terminal network can be replaced by a single voltage source **VTh** in series with resistance **RTh**.
   - VTh = open-circuit voltage across terminals.
   - RTh = equivalent resistance looking into terminals with all sources **removed (V→short, I→open)**.

3. **Norton's theorem:** The same network = a current source **IN** in parallel with resistance **RN = RTh**.
   - IN = short-circuit current through terminals.
   - Relation: `IN = VTh / RTh`.

4. **Maximum power transfer:** Maximum power delivered to load when **RL = RTh**.
   `Pmax = VTh² / 4RTh`

### AC circuits (R, L, C)
| Element | Impedance | Phase |
|---|---|---|
| R | R | 0° (in phase) |
| L | jωL (XL = 2πfL) | current lags voltage by 90° |
| C | 1/jωC (XC = 1/2πfC) | current leads voltage by 90° |

- **Impedance Z** for series R-L-C : `Z = √(R² + (XL − XC)²)`.

### Resonance
- **Series resonance (RLC series):** `XL = XC` → `fr = 1/(2π√(LC))`. At resonance: **Z is minimum = R**, current maximum, circuit is resistive, PF = 1. **Q factor = XL/R** (Q = 1/R·√(L/C)). Bandwidth `BW = fr/Q`.
- **Parallel resonance:** at resonance **Z is maximum**, current minimum.

### Power in AC
- **Active power P = VI·cosφ** (watts) — consumed.
- **Reactive power Q = VI·sinφ** (VAR).
- **Apparent power S = VI** (VA).
- **Power factor = cosφ = P/S** (φ = angle between V and I).
- Power triangle: `S² = P² + Q²`.

## 1.3 Alternating Current Fundamentals

### Generation
AC is generated by a conductor rotating in a magnetic field. Instantaneous value:
```
v(t) = Vm·sin(2πft + φ)   where Vm = peak value, f = frequency
```

### AC wave parameters
- **Peak value (Vm):** maximum instantaneous value.
- **Peak-to-peak:** 2Vm.
- **Average value** (half cycle, sine): `Vavg = 2Vm/π ≈ 0.637 Vm`.
- **RMS value:** `Vrms = Vm/√2 ≈ 0.707 Vm` (for sine wave).
- **Form factor** = RMS/avg = 1.11 (sine).
- **Peak/crest factor** = peak/RMS = √2 (sine).
- **Angular frequency ω = 2πf** (rad/s); **period T = 1/f**.
- Nepal mains: **230 V (RMS), 50 Hz**.

### Three-phase system
- Three voltages displaced by **120°**.
- **Star (Y):** `VL = √3·Vph`, `IL = Iph`. Neutral point available.
- **Delta (Δ):** `VL = Vph`, `IL = √3·Iph`.
- **Balanced system:** total power `P = √3·VL·IL·cosφ`.
- Advantages: constant total power, smaller conductors, better efficiency.

## 1.4 Semiconductor Devices

### PN Junction diode
- **Forward bias** (P-positive, N-negative): conduction below barrier; small voltage drop (~0.7 V Si, 0.3 V Ge).
- **Reverse bias:** tiny leakage current; **breakdown** at very high reverse voltage.
- Diode is a **unilateral, nonlinear** device.
- **Zener diode:** operates in **reverse breakdown** region → used as **voltage regulator**.

### BJT (Bipolar Junction Transistor)
- Three terminals: **Emitter, Base, Collector**. Types: **NPN, PNP**.
- **Current-controlled** device. `IC = β·IB` (β = dc current gain, typical 50–300). `IE = IB + IC`.
- **Configurations:**
  | Config | Gain | Phase | Application |
  |---|---|---|---|
  | Common Emitter (CE) | Voltage + current gain (high) | **Inverts (180°)** | Most common amplifier |
  | Common Base (CB) | Voltage gain only, low input Z | No inversion | High-frequency amp |
  | Common Collector (CC) | Current gain, voltage gain ≈1 | No inversion | **Emitter follower/buffer** |
- **Biasing:** fixed bias, collector feedback, **voltage-divider bias** (most stable).
- Operating regions: cutoff, active (amplifier), saturation (switch).

### MOSFET
- Four terminals: Gate, Drain, Source, Body. **Voltage-controlled** device (gate voltage controls current).
- Types: **enhancement** (normally OFF) & **depletion** (normally ON).
- High input impedance (no gate current), low switching loss.
- **CMOS** = complementary (NMOS + PMOS) — used for digital logic; CMOS inverter consumes power mainly during switching.

### Small vs large signal
- **Small-signal model:** linearized (h-parameters, transconductance gm) around Q-point for amplifier analysis.
- **Large-signal model:** switches/rectifiers (diode ON/OFF), saturation analysis.

## 1.5 Signal Generators (Oscillators)

### Oscillator basics
- Converts **DC to AC without input signal** using **positive feedback**.
- **Barkhausen criterion:** (1) loop gain |Aβ| ≥ 1; (2) total phase shift around loop = 0° (or 360°).
- Two parts: amplifier + feedback network that selects frequency.

### Types
| Oscillator | Frequency | Notes |
|---|---|---|
| **RC phase-shift** | Audio (low f) | 3 RC sections, 180° shift each stage config |
| **Wien bridge** | Audio | Balanced bridge + op-amp |
| **LC oscillators (Colpitts, Hartley)** | RF (high f) | Colpitts: capacitive divider; Hartley: inductive divider |
| **Crystal oscillator** | Very accurate | Piezoelectric quartz; highest frequency stability |

### Waveform generators
- **Astable multivibrator (555):** free running, produces square wave, no stable state.
- **Monostable (555):** one stable state; triggered → one output pulse.
- **Bistable:** two stable states (flip-flop).
- Sinusoidal/square/triangle/sawtooth generators.

## 1.6 Amplifiers

### Power amplifier classes
| Class | Conduction | Max efficiency | Distortion |
|---|---|---|---|
| **A** | 360° (full cycle) | ~25–50% (25% direct) | Lowest |
| **B** | 180° | ~78.5% | crossover distortion |
| **AB** | slightly >180° | 50–78.5% | low (used in push-pull) |
| **C** | <180° | very high (~80–90%) | high (tuned/radio) |

- **Push-pull amplifier:** two transistors, one conducts per half cycle; **crossover distortion** eliminated by **class-AB biasing**.
- **Transformer-coupled push-pull:** DC blocking + impedance matching.
- **Tuned amplifiers:** LC load, narrow band (RF).

### Op-amp (Operational Amplifier) — high gain differential amplifier
- **Virtual ground:** in negative feedback, inverting input nearly = non-inverting input.
- Golden rules: (1) no current flows into input terminals (infinite input impedance); (2) V+ ≈ V− (virtual short).
- **Inverting amp:** `Av = −Rf/Rin`.
- **Non-inverting amp:** `Av = 1 + Rf/Rin`.
- **Voltage follower/buffer:** `Av = 1` (unity gain).
- **Ideal op-amp:** infinite open-loop gain, infinite input Z, **zero output impedance**, infinite bandwidth.
- **CMRR** (common-mode rejection ratio): ability to reject common-mode signals; higher is better.
- **Slew rate:** max rate of output voltage change (V/µs).
- Applications: amplifier, adder, subtractor, integrator, differentiator, comparator, buffer.
